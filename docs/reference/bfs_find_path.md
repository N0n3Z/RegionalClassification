# BFS path finder

BFS path finder

## Usage

``` r
bfs_find_path(from, to, graph, only_simple = FALSE)
```

## Arguments

- from:

  Starting node

- to:

  Target node

- graph:

  Adjacency list

- only_simple:

  If TRUE, only traverse 1:1 and N:1 edges

## Value

list with path, relations, edges_used, or NULL
