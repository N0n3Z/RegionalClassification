# Load all raw data files and return a named list of data.tables

Load all raw data files and return a named list of data.tables

## Usage

``` r
load_all_raw_data(data_dir = get_raw_data_path(), file_mapping = FILE_MAPPING)
```

## Arguments

- data_dir:

  Path to the raw data directory

- file_mapping:

  The FILE_MAPPING configuration from 00_config.R

## Value

Named list of data.tables
