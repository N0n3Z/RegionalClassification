# nbbbenuts: Belgian Geographic Classification Converter

Tools to convert Belgian geographic codes between classification systems
(NIS communes, NUTS regions, postal codes) and across time versions (NIS
BEFORE_2019, 2019, 2025; NUTS 2021, 2027). Includes dataset-level
conversion, weighted splitting of ambiguous M:N mappings, and
classification diagnostics.
